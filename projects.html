项目与下载

每个包都注明了适用游戏版本和限制;压缩包里自带中文说明,解压就能用。下载前请连同下面的使用范围一起看。

下载与校验

  • 文件放在本仓库的 GitHub Releases 里(站点本身只有网页文件,不含任何可执行文件)。 点下载会直接跳到对应 Release 的附件。
  • 每个附件都列了 SHA256。Windows 上核对: 
    certutil -hashfile 文件名 SHA256
    输出与页面上的值一致即可。
  • 杀毒软件对加载器类的程序报警很常见,多半是误报。不放心就别用 —— 我不劝你关杀软、也不劝你加白名单。
  • 游戏更新后工具可能失效。等对应版本的新包,不要自己去改包里的文件。
  • 每个包都不含源码,也不含任何需要额外安装的运行库。

使用范围

全部只针对单人 / 剧情模式。

  • 不要用于任何多人对局:官方多人服、社区服、联机 Mod 都不要。
  • 在多人环境使用第三方工具通常违反游戏服务条款,账号风险由使用者承担。
  • 这些工具不含、也不会提供任何规避检测或对抗反作弊的功能。
  • 请自行确认你所在地区的相关规定,以及这样做是否符合你认为值得的程度。

装坏了怎么办

  • 每个包都是"删文件即卸载":看对应文章里的卸载步骤,把放进游戏目录的文件删掉即可。
  • 游戏出现异常先删掉文件再启动一次;还有问题就重启游戏,别反复叠加安装。
  • 把日志文件发我(每个包都会在它所在的目录或游戏目录生成日志),我能看出失败在哪一步。
