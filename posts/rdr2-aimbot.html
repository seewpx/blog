荒野大镖客 2 剧情模式辅助:部署与配置

2026-08-31 · 版本 20260831 · 仅剧情模式

荒野大镖客 2 剧情模式用的自动瞄准 + 方框透视:按住右键把准星拉向最近的交战目标头部并保持,同屏敌人用方框标出来。解压进游戏根目录就能用,不需要额外装任何前置组件。

只用于剧情模式。Red Dead Online(线上模式)绝对不要用 —— 线上环境对第三方文件的处置是明确的,封号后果自负。

功能

  • 自动瞄准:按住右键(且持有武器)时,准星自动拉向最近的敌对目标头部并保持。
  • 方框透视(F7 轮换):全部 / 仅动物 / 仅人类 / 关闭,穿墙可见。
  • 只锁交战目标:默认不锁平民和旁观者;动物不受这个限制。
  • 骑马补偿:骑马时自动补偿地形坡度,避免准星系统性偏上。
  • 配置热重载(F9):改完配置文件按一下就好,不用重启游戏。

安装

  1. 关闭游戏。
  2. 把压缩包里的四个文件(dinput8.dll、rdr2hook.dll、rdr2_aimbot.asi、rdr2-aimbot.cfg)复制到游戏根目录(Steam 默认是 ...\steamapps\common\Red Dead Redemption 2\),不是 bin 子目录。
  3. 启动游戏,进入剧情模式。
  4. 确认装上:游戏根目录出现 rdr2hook.log 和 rdr2-aimbot.log 两个日志文件。没出现就说明加载文件没被游戏读取,见下面排错。

热键

键作用
F5自动瞄准总开关(日志出现 aimbot ENABLED 即已开启)
鼠标右键(按住)开瞄:准星拉向最近目标头部并锁住;需要持有武器
F7透视方框轮换:全部 → 仅动物 → 仅人类 → 关
F9重新读取配置文件(改完不用重启游戏)
F6调试日志开关(锁定状态下约每秒两行目标数据,调参用)

常用配置(改完按 F9)

键说明
aim_radius锁定 / 透视的最大距离(米),默认 60
fov_yaw / fov_pitch平时的视野角(度)。缩小可减少误锁
fov_aim_yaw / fov_aim_pitch开瞄时的视野角,决定「多偏的敌人也拉得过来」
require_los1 = 锁定需要视线无遮挡(透视不受影响),默认 1
exclude_friendly1 = 只锁敌人;0 = 无差别锁头(含平民)
target_priority0 = 按准星方向优先;1 = 按距离最近
require_aiming1 = 按住右键才生效;0 = 持械即生效
esp_mode启动时的透视模式:0 关 / 1 动物 / 2 人类 / 3 全部
esp_armed_only1 = 只在持械时显示方框
head_offset_z头部命中点微调(米),默认 -0.05
mounted_pitch_bias骑马时的俯仰补偿起点:感觉偏上就加大,偏下就减小(每次 ±0.2)

配置文件里还有几个预留键(require_combat、require_human、aim_height_z、animal_head_factor,以及 sensitivity / smoothing / dead_zone / yaw_sign / pitch_sign)当前版本不影响实际瞄准,别改它们,免得排查时误判。

默认行为

  • 只锁与玩家交战的敌人;平民、旁观者不锁;动物不受限制。
  • 开瞄才生效(按住右键);锁定距离 60 米,目标需在视野角内。
  • 透视不受距离和视线限制,看到就能框出来。

出问题先看这几条

  • 游戏目录没有 rdr2hook.log:加载文件没被游戏读取。确认四个文件在游戏根目录(不是 bin 子目录),并把游戏目录加进杀软白名单后重试。
  • 锁不住 / 锁错人:缩小 fov_aim_yaw、fov_aim_pitch,或调小 aim_radius;只想锁敌人就保持 exclude_friendly = 1。
  • 骑马时准星偏上 / 偏下:调 mounted_pitch_bias(每次 ±0.2),改完按 F9。
  • 游戏大版本更新后失效:等新版包。旧包在大版本上不保证能用。
  • 卸载:删掉放进游戏目录的那四个文件即可;之前覆盖过别的加载文件,自己恢复备份。
